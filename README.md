# وب‌سایت نماد نیرو

سایت شرکت نماد نیرو — ساخته‌شده با [Astro](https://astro.build). خروجی تقریباً همه‌اش فایل‌های HTML ثابت است؛ بدون وردپرس، بدون دیتابیس. فقط یک فایل PHP کوچک (`send-quote.php`) برای ارسال فرم درخواست مشاوره وجود دارد — یعنی هاست باید PHP را پشتیبانی کند (هر هاست اشتراکی معمولی، از جمله هاست فعلی، این را دارد).

---

## اجرا روی سیستم خودتان

```bash
npm install       # فقط بار اول
npm run dev       # http://localhost:4321
```

ساخت نسخهٔ نهایی:

```bash
npm run build     # خروجی در پوشهٔ dist/
npm run preview   # پیش‌نمایش خروجی نهایی
```

## افزودن و ویرایش محتوا

### مقالهٔ جدید (مجله)

یک فایل تازه در `src/content/articles/` بسازید، مثلاً `my-article.md`:

```markdown
---
title: "عنوان مقاله"
category: edu        # edu | market | news
date: "۱۴۰۴/۰۵/۱۲"
readTime: 5
draft: false         # true یعنی منتشر نشود
---

متن مقاله اینجا نوشته می‌شود. می‌توانید **بولد**، فهرست و تصویر بگذارید.
```

صفحهٔ مقاله، لینکش در فهرست مجله و بخش «مطالب مرتبط» خودکار ساخته می‌شود.

### محصول جدید (فروشگاه)

به `src/data/products.json` اضافه کنید:

```json
{
  "id": "شناسه-یکتا",
  "name": "نام محصول",
  "brand": "SUNGROW",
  "spec": "۱۰",
  "specUnit": "kW · سه‌فاز",
  "cat": "industrial",   // home | industrial
  "kind": "inverter",    // inverter | panel | storage | accessory
  "featured": false,     // true یعنی در صفحهٔ اصلی هم بیاید
  "order": 17
}
```

### پروژهٔ جدید

به `src/data/projects.json` اضافه کنید:

```json
{
  "id": "شناسه-یکتا",
  "name": "نام کارفرما",
  "capacity": "۵",
  "unit": "MW",
  "tag": "تأمین پنل",
  "cat": "supply",       // supply | build | invest
  "note": "توضیح کوتاه",
  "featured": false,
  "order": 30
}
```

### متن‌های ثابت سایت

منو، آمار، حوزه‌های فعالیت، برندها و کارفرمایان همگی در یک فایل هستند:
`src/data/site.ts`

## تصاویر

تصاویر محتوایی در `src/assets/` قرار دارند تا Astro آن‌ها را **خودکار بهینه کند**
(تبدیل به WebP، ساخت اندازه‌های مناسب موبایل و دسکتاپ، و بارگذاری تنبل).
برای جایگزینی، فایل هم‌نام را عوض کنید — بقیهٔ کارها خودکار انجام می‌شود.

فقط فایل‌هایی که باید آدرس ثابت داشته باشند (لوگو و لوگوی برندها) در
`public/assets/` مانده‌اند.

| فایل | کاربرد | ابعاد |
|---|---|---|
| `activity-1/2/3.jpg` | اسلایدر صفحهٔ اصلی | ۲۵۶۰×۱۰۶۷ (نسبت ۲٫۴:۱) |
| `banner-1/2.jpg` | بنر صفحهٔ اصلی | ۱۶۰۰×۴۰۰ |
| `area-1/2/3.jpg` | صفحهٔ حوزه‌های فعالیت | ۱۲۰۰×۹۰۰ |
| `project-1/2/3.jpg` | پروژه‌های منتخب | ۹۰۰×۱۱۰۰ و ۱۲۰۰×۷۲۰ |
| `brands/*.png` | لوگوی برندها | ~۳۰۰×۱۲۰ |
| `products/*.jpg` | عکس صفحهٔ هر محصول | مربعی، حداقل ۷۰۰×۷۰۰ |

عکس ۷ محصول (فرونیوس، سانگرو، سانویز، AE Solar) از سایت فعلی نمادنیرو گرفته شده. برای محصولات Deye، Goodwe، Sineng و Trina — که در فروشگاه فعلی سایت زنده وجود ندارند — هنوز عکس واقعی نداریم؛ تا وقتی عکس اضافه نشود، به‌جای عکس، نام برند نمایش داده می‌شود (طبق همان الگوی fallback فعلی).

## فرم درخواست مشاوره (Quote Form)

فرم روی صفحهٔ اصلی (`#quote`) و صفحهٔ «تماس با ما» داده را با `fetch` به `send-quote.php` می‌فرستد — یک اسکریپت PHP ساده که خودمان روی همین هاست میزبانی می‌کنیم، بدون وابستگی به هیچ سرویس شخص‌ثالث. ایمیل مقصد در بالای `public/send-quote.php` تنظیم شده: `sales@namadniroo.ir`.

اگر مقصد باید عوض شود، فقط مقدار `$to` در `public/send-quote.php` را ویرایش کنید.

نکته: چون از `mail()` استاندارد PHP استفاده می‌شود، برای رسیدن مطمئن ایمیل به اینباکس (و نه پوشهٔ اسپم)، بهتر است رکورد SPF دامنه در پنل هاست فعال باشد — روی هاست‌های cPanel معمولاً به‌صورت خودکار برای دامنهٔ اصلی تنظیم می‌شود.

## انتشار

سایت یک اپ کاملاً استاتیک است (به‌جز چند فایل PHP کوچک برای فرم و پنل لیدها)، پس روی هر هاست معمولی PHP/Apache (مثل هاست فعلی نماد نیرو) کار می‌کند.

### انتشار خودکار (روش اصلی)

با هر `git push` روی شاخهٔ `main`، اکشن گیت‌هاب سایت را می‌سازد و روی هاست آپلود می‌کند.
برای فعال‌شدن، این چهار مقدار باید یک‌بار در
`Settings → Secrets and variables → Actions` مخزن تعریف شوند:

| نام | مقدار |
|---|---|
| `FTP_SERVER` | مثلاً `ftp.namadniroo.ir` |
| `FTP_USERNAME` | نام کاربری اکانت FTP مخصوص دیپلوی |
| `FTP_PASSWORD` | رمز همان اکانت |
| `FTP_DIR` | مسیر مقصد، مثلاً `/public_html/` |

توصیه: یک اکانت FTP **جداگانه** فقط برای دیپلوی بسازید، نه اکانت اصلی هاست.

### انتشار دستی (در صورت نیاز)

```bash
npm run build     # خروجی در پوشهٔ dist/
```

سپس محتوای پوشهٔ `dist/` (نه خود پوشه) را در ریشهٔ هاست آپلود کنید.

## پنل درخواست‌ها

همهٔ درخواست‌های فرم، پیش از ارسال ایمیل، در یک دیتابیس SQLite ذخیره می‌شوند؛
بنابراین حتی اگر ایمیل هاست از کار بیفتد هیچ درخواستی گم نمی‌شود.

- مشاهدهٔ درخواست‌ها و خروجی CSV: `namadniroo.ir/leads/`
- فایل دیتابیس **بیرون از پوشهٔ وب** ساخته می‌شود، پس از طریق مرورگر قابل دانلود نیست
  و با هر انتشار جدید هم پاک نمی‌شود.

> ⚠️ **کار لازم پس از اولین انتشار:** پوشهٔ `/leads` را از پنل هاست
> (cPanel → Directory Privacy) با نام کاربری و رمز محافظت کنید.
> بدون این کار، اطلاعات تماس مشتریان برای همه قابل مشاهده است.

## نکات فنی

- **راست‌چین (RTL):** سراسر سایت. جهت حرکت اسلایدرها دستی مدیریت شده است.
- **فونت:** دانا، از `public/fonts/`، به‌صورت متغیر (وزن ۱۰۰ تا ۹۰۰).
- **رنگ‌های برند:** در `:root` فایل `global.css` — زرد `#FFC41A`، سرمه‌ای `#0A3D5D`.
- **دسترس‌پذیری:** فوکوس با کیبورد، احترام به `prefers-reduced-motion`.
- **فروشگاه:** فعلاً لیدجن است («استعلام قیمت»). فیلدهای `price`، `sku` و `inStock` در ساختار داده آماده‌اند تا در آینده سبد خرید اضافه شود.
